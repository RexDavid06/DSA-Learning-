The OOP skills that matter in real projects

For a Django/backend developer, these are more important than knowing definitions:

Composition

Instead of:

class Car(Vehicle):
    pass

you often do:

class Car:
    def __init__(self):
        self.engine = Engine()

A car has an engine.

This is called composition and is used everywhere.

SOLID Principles

Learn:

Single Responsibility Principle
Open/Closed Principle
Liskov Substitution Principle
Interface Segregation Principle
Dependency Inversion Principle

Don't memorize them. Build small projects and see them in action.

Design Patterns

Start with:

Factory Pattern
Strategy Pattern
Singleton Pattern (know it, don't overuse it)

You'll find these in large Django codebases.
